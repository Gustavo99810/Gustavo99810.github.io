# Cobalt Night Blues

Ferramenta pessoal para enviar vídeos automaticamente ao canal
do YouTube do proprietário.

A ferramenta utiliza a YouTube Data API e a autorização OAuth
do Google para realizar os envios autorizados pelo proprietário.
Não oferece cadastro ou acesso ao público.
